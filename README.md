Model Training:-
The data is split into training and test sets (usually 80/20), and the models are trained.

Logistic Regression: Learns a linear boundary between classes and outputs a probability for each class. It usually performs very well on TF-IDF features and is the stronger choice for this task.
Naive Bayes (Multinomial): A fast probabilistic model that assumes features are independent. It trains quickly and works as a good baseline, though it is typically slightly less accurate here.
